# IPL Data Analysis Project

## Project Overview

This project analyzes Indian Premier League (IPL) cricket data using Python and data visualization libraries. The objective of this project is to discover insights about IPL teams, players, venues, and match trends.

The analysis includes:
- Most successful IPL teams
- Best player performance
- Toss winner analysis
- Venue analysis
- Season-wise match trends

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code

---

# Dataset Information

Dataset used:
- IPL Match Dataset (2008–2025)

Dataset contains:
- Match winners
- Teams
- Venues
- Toss winners
- Seasons
- Player of match awards

# Key Insights

- Mumbai Indians is one of the most successful IPL teams.
- Chennai Super Kings has shown consistent performance across seasons.
- Certain venues host significantly more IPL matches.
- Toss winning may influence match results in some seasons.
